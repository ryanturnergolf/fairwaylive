# UI Review

Use this prompt when reviewing Clubhouse HQ user experience.

## Goal

Review UX quality, mobile behavior, and confusing flows without changing behavior.

## Checklist

- Review the relevant route or component in desktop and mobile contexts.
- Check whether primary actions are clear.
- Check whether form labels, button states, loading states, and error states are understandable.
- Check whether mobile scorecard and tournament workflows remain usable on small screens.
- Detect confusing flows, dead ends, duplicated calls to action, and unclear state transitions.
- Recommend improvements without changing product behavior unless explicitly asked.

## Constraints

- Do not change scoring rules.
- Do not change persistence behavior.
- Do not redesign unrelated screens.
- Do not modify files during review unless explicitly instructed.

## Final Report

Report:

- UX strengths.
- Confusing or risky flows.
- Mobile-specific issues.
- Recommended improvements.
- Which recommendations are behavior-preserving.
